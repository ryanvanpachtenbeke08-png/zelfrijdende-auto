# Zelfrijdende Auto met Arduino 🚗🤖

Welkom op de GitHub-pagina van ons project! In deze repository werken wij als team volgens de **Scrum-methode** aan het ontwerpen, bouwen en programmeren van een zelfrijdende auto op basis van een **Arduino**.

![Afbeelding van onze zelfrijdende auto](auto.jpg)
*(Vervang `auto.jpg` door de exacte bestandsnaam van jullie eigen geüploade foto of schets)*

## 🎯 Doel van het project
Het doel van dit project is om een autonome wagen te bouwen die zelfstandig een parcours kan afleggen en obstakels kan ontwijken (of een lijn kan volgen) met behulp van sensoren en motoren.

## 🛠️ Gebruikte onderdelen (Hardware)
* Arduino Uno (of Nano/Mega)
* Motor driver (bijv. L298N)
* DC-motoren + wielen & chassis
* Ultrasone afstandssensor (HC-SR04) / Lijnvolgsensoren
* Batterijhouder & jumper wires
